# AGENTS.md

## Repo type

NixOS flake-based system configuration for two hosts:

- **zenbook** — ASUS Zenbook laptop, user `alex` (primary desktop)
- **coral** — headless/server host, user `actuary`

## Commands

```bash
# Build and activate (requires sudo)
sudo nixos-rebuild switch --flake .#zenbook
sudo nixos-rebuild switch --flake .#coral

# Dry-build without switching
sudo nixos-rebuild build --flake .#zenbook

# Update all flake inputs
nix flake update

# Format all .nix files (uses alejandra)
nix fmt

# Validate flake
nix flake check
```

There are no tests, lint, or typecheck commands. `nix flake check` and a successful `nixos-rebuild build` are the only verification steps.

## Architecture

Entry point: `flake.nix` — single `nixosConfigurations` output with two hosts.

**Two-layer structure:**
- `nixos/` — system-level config (root, whole system)
- `home-manager/` — user-level config (dotfiles, user packages, desktop apps)

### Key wiring

- Flake inputs are passed to all modules via `specialArgs = {inherit inputs outputs;}`.
- Overlays from `overlays/default.nix` are applied in each host's `configuration.nix` (not in flake.nix).
- Home-manager is embedded as a NixOS module (not standalone). Config lives in `home-manager/home.nix` and is wired per-host in `flake.nix`.
- `home-manager.backupFileExtension = "backup"` is set in `nixos/configuration.nix` — existing dotfiles get `.backup` suffix on conflict.

### Overlay pattern

Three overlays defined in `overlays/default.nix`:
- `additions` — custom packages from `pkgs/` (currently empty)
- `modifications` — patched upstream packages (pcloud override)
- `unstable-packages` — exposes nixpkgs-unstable as `pkgs.unstable.*`

To use an unstable package anywhere: `pkgs.unstable.packageName`.

### Stylix theming

Theming is centralized via Stylix in `nixos/desktop.nix`. Uses Dracula base16 scheme. Stylix auto-themes many apps. Custom wallpaper is fetched via `pkgs.fetchurl` — the sha256 comment in that file documents how to regenerate the hash.

### Display management

Monitor profiles are handled by **Kanshi** (`services.kanshi` in `home-manager/home.nix`), not by Hyprland monitor config. `home-manager/hypr/monitors.nix` explicitly defers to Kanshi. When editing display settings, edit the Kanshi profiles in `home.nix`.

## File map

### nixos/ (system)

| File | Purpose |
|------|---------|
| `configuration.nix` | Core: users, networking, Docker, SSH, nix settings, overlay application |
| `desktop.nix` | Hyprland WM, SDDM, Stylix config, system desktop packages |
| `building.nix` | Remote builder config (not imported by default — check if needed) |
| `hardware/storage.nix` | NFS mounts to Unraid server |
| `hardware/printer.nix` | Canon printer via CUPS |
| `configs/fonts.nix` | System fonts |
| `configs/wireguard.nix` | WireGuard firewall rules |
| `hosts/coral/` | Coral host: Docker, GitHub runner, Plex (commented out), storage |

### home-manager/ (user: alex)

| File | Purpose |
|------|---------|
| `home.nix` | User packages, session vars, git config, Kanshi profiles — imports everything else |
| `hypr/hyprland.nix` | Keybindings, window rules, animations |
| `hypr/hyprpanel.nix` | Bar config |
| `hypr/hyprlock.nix` | Lock screen |
| `hypr/hypridle.nix` | Idle timeouts (5min lock → 5.5min DPMS → 30min suspend) |
| `hypr/hyprpaper.nix` | Wallpaper |
| `hypr/monitors.nix` | ASUS keyboard backlight bindings; display config deferred to Kanshi |
| `vscode.nix` | VS Code extensions and settings |
| `kitty.nix` | Terminal config |

| `theme/icons.nix` | Icon theme |

### overlays/ and pkgs/

`overlays/default.nix` — three overlays (see above). `pkgs/default.nix` — empty placeholder for custom packages.

### modules/

`modules/nixos/default.nix` and `modules/home-manager/default.nix` — empty placeholders for reusable modules to potentially upstream.

## Gotchas

- `nixos/hardware/zenbook/hardware-configuration.nix` is auto-generated by `nixos-generate-config`. Don't edit it manually; regenerate if hardware changes.
- `nixos/building.nix` defines a remote builder but is **not imported** in any configuration by default. It's a reference/template.
- The `coral` host does not import Stylix, Hyprland, or desktop modules — it's a headless server.
- Coral uses `home-manager` but with its own `home.nix` at `nixos/hosts/coral/home.nix`, not `home-manager/home.nix`.
- `pkgs/` is currently empty (no custom packages). `modules/` directories are also empty placeholders.
- The `zen-browser` flake input is commented out in the `outputs` destructuring but still passed via `inputs` — it's accessed as `inputs.zen-browser.packages` in `desktop.nix`.
- Flake inputs use `nixpkgs` (unstable) as the base. There is no stable nixpkgs input.
- `nix.gc` is configured for weekly garbage collection, deleting generations older than 7 days.
